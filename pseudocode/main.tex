\section{Introduction}
The following document contains the pseudocode for the C++ version of the Model Of the Swedish Economic System (MOSES) as of February 2025. The project was first designed in A Programming Language (APL). In 2023, it was converted to a preliminary C++ model based on the preliminary pseudocode from 1976. In 2025, the updated APL project was converted with the help of the pseudocode from 1989. The following pseudocode is largely equivalent to the pseudocode from 1989. There are minor changes that replicate the most updated APL version instead of the pseudocode. The pseudocode from 1989 has small differences to the current APL project. This pseudocode and the C++ model should be regarded as a hybrid between the two.

This pseudocode has two purposes. First, it adjusts the differences from the older pseudocode. Second, it replicates C++'s object-oriented structure and style, which increases readability.

In object-oriented coding, classes are templates of objects. For example, the Firm class describes the properties of a firm. The Firm class may contain variables such as margin, price, and sales. Variables refer locally to their respective class instances. In other words, the sales variable $s$ is not a globally defined array of all sales. It is the sales of a specific company. Classes also contain functions, called methods. These specify functionality of individual class instances. To initialise the production plan of a particular firm, for example, a firm calls $Firm::init\_prodplan$.

Furthermore, the C++ implementation has polymorphic characteristics. Explicitly producing sectors (Market) and externals sectors (External) share functionality. They are both sectors, but differ in significant ways. This is programmatically implemented by classifying the Market and External classes as children of the Sector class. In other words, the classes inherit from their base class Sector. They are types of the Sector class. All markets and externals have copies of all Sector variables, but Market instances do not have copies of External-specific variables and vice versa. All sectors have an id, but only externals have the $x$ variable, and only markets have the $io$ variable, for example. The same rule applies to methods. For instance, both classes have their own variant of the $quarterly\_exp$ function, which is first declared in the Sector class, and later implemented in the Market and External classes for their respective specific differences. Market-specific and External-specific methods are only part of their respective class.

The MOSES model is a very tightly coupled system. Different classes rely heavily on each other for functionality. The input-output coefficients for firms in a market are stored in the Market class, and not in the Firm class for instance. Therefore, firms must access their respective Market instances for access to that variable. The downside of such a design is that the pseudocode may become ambiguous, especially since multiple classes can have the same variable name. For example, the Household and the Government classes have the variable $qint$. To remove ambiguity, assume that variables within methods refer to that class unless specified otherwise. The same applies to loops. For example, if a calculation is computed for every firm, it should first be assumed that the calculation refers to the firms' variables. In more complicated cases, ambiguity is removed by adding a note under the function, or by prefixing the variable with the correct class. For instance, in a calculation involving both government and household receipts, the variables would appear like this: $Government::qint$, $Household::qint$.

It should be noted that C++ is a 0-indexed programming language. The first item of an array is accessed with a zero index, not the number one. Therefore, the index-variable for the durables sector is two instead of three for example.

The structure of the model can always be improved. It is difficult to achieve perfectly consistent naming since C++-specific terms limit naming. For example, government interest receipts on a yearly basis are named $intg$ instead of $int$ since $int$ refers to the integer datatype.

In addition, variable classification can be discussed. For instance, it can be argued that household tax variables should be in the Household class since they refer to households. On the other hand, one may argue that all tax variables should be contained in the Government class since the government regulates taxes.

The complete MOSES simulation is overviewed in \autoref{fig:MOSES-block-diagram-1}. The diagram is read from top to bottom and from left to right. Each module represents an important function. The simulation starts in $Simulate$, enters $Initialise$ before $Simulate$ $Year$, and completes $Prodplan$'s sub-modules before moving on to $Labour$ $Market$.

The project source code is located in the public Github repository: \href{https://github.com/novrion/MOSES}{github.com/novrion/MOSES}.

\section{Main Simulation}

\begin{algorithm}[H]
\caption{Simulate}
\begin{algorithmic}
        \Function{simulate}{}
            \State \Call{initialise}{}
            \ForAll{years}
                \State \Call{simulate\_year}{}
                \State $year = year + 1$
            \EndFor
        \EndFunction
\end{algorithmic}
\end{algorithm}

\begin{algorithm}[!htbp]
\caption{Simulate Year}
\begin{algorithmic}
    \Function{simulate\_year}{}
        \State \Call{yearly\_init}{}
        \ForAll{firms}
            \State \Call{yearly\_exp}{}
            \State \Call{yearly\_targ}{}
        \EndFor
        \For{$relative\_quarter = 0, 1,\dots,3$}
            \State \Call{simulate\_quarter}{}
            \State $quarter = quarter + 1$
        \EndFor
        \ForAll{firms}
        \State \Call{Firm::yearly\_update}{}
        \EndFor
    \EndFunction
\end{algorithmic}
\end{algorithm}

\begin{algorithm}[!htbp]
\caption{Simulate Quarter}
\begin{algorithmic}

        \State \Call{quarterly\_exp}{}
        \State \Call{prodplan}{}
        \State \Call{labour\_market}{}
        \State \Call{export\_market}{}
        \State \Call{domestic\_market}{}
        \ForAll{firms}
        \State \Call{finalqpqsqm}{}
        \State \Call{quarterly\_cum}{}
        \EndFor
        \State \Call{invfin}{}
        \State \Call{government\_accounting}{}
        \State \Call{national\_accounting}{}
        \EndFunction
\end{algorithmic}
\end{algorithm}

\subsection{Yearly Expectations and Target}

\begin{algorithm}[H]
\caption{Yearly Exp}
    \begin{algorithmic}
    \Function{Firm::yearly\_exp}{}
        \State \(histdp = smp * histdp + (1 - smp) * dp\)
        \State  \(histdpdev = smp * histdpdev + (1 - smp) * (dp - expdp)\)
        \State  \(histdpdev2 = smp * histdpdev2 + (1 - smp) * (dp - expdp)^2\)
        \State  \(expidp = histdp + e1 * histdpdev - e2 * \sqrt{histdpdev2}\)
        \State  \(expdp = (1 - r) * expidp + r * expxdp\)
        \\
        \State  \(histdw = smw * histdw + (1 - smw) * dw\)
        \State  \(histdwdev = smw * histdwdev + (1 - smw) * (dw - expdw)\)
        \State  \(histdwdev2 = smw * histdwdev2 + (1 - smw) * (dw - expdw)^2\)
        \State  \(expidw = histdw + e1 * histdwdev + e2 * \sqrt{histdwdev2}\)
        \State  \(expdw = (1 - r) * expidw + r * expxdw\)
        \\
        \State  \(histds = sms * histds + (1 - sms) * ds\)
        \State  \(histdsdev = sms * histdsdev + (1 - sms) * (ds - expds)\)
        \State  \(histdsdev2 = sms * histdsdev2 + (1 - sms) * (ds - expds)^2\)
        \State  \(expids = histds + e1 * histdsdev - e2 * \sqrt{histdsdev2}\)
        \State  \(expds = (1 - r) * expids + r * expxds\)
    \EndFunction
    \end{algorithmic}
\end{algorithm}

\begin{algorithm}[H]
\caption{Yearly Targ}
    \begin{algorithmic}
        \Function{Firm::yearly\_targ}{}
        \State $mhist = \Call{max}{0, smt * mhist + (1 - smt) * m}$
        \State $targm = mhist * (1 + eps)$
        \EndFunction
    \end{algorithmic}
\end{algorithm}

\subsection{Yearly Update}

\begin{algorithm}[H]
\caption{Yearly Update}
    \begin{algorithmic}
        \Function{Firm::yearly\_update}{}
        \State $dq = \frac{cumq}{q} - 1$
    	\State $q = q * (1 + dq)$
    	\State $dp = \frac{cums}{cumsu * p} - 1$
    	\State $p = p*(1 + dp)$
    	\State $dw = \frac{cumws}{cuml * w} - 1$
    	\State $w = w*(1 + dw)$
    	\State $ds = \frac{cums}{s} - 1$
    	\State $s = s*(1 + ds)$
    	\State $dva = \frac{cumva}{va} - 1$
    	\State $va = va*(1 + dva)$
    	\State $snet = cumsnet$
    	\State $chm = cumm - m$
    	\State $m = m+chm$
        \EndFunction
    \end{algorithmic}
\end{algorithm}

\begin{algorithm}[!htbp]
\caption{Quarterly Exp (Firm)}
    \begin{algorithmic}
        \Function{Firm::quarterly\_exp}{}
        \State \(qexpdp=\frac{expdp}{4}\)
        \State \(qexpdw=\frac{expdw}{4}\)
        \State \(qexpds=\frac{expds}{4}\)
        \If{last quarter in year}
        \State \(qexpdp=qexpdp+fip*(qdp-qexpdp)\)
        \State \(qexpdw=qexpdw+fiw*(qdw-qexpdw)\)
        \State \(qexpds=qexpds+fis*(qds-qexpds)\)
        \EndIf
        \State \(qexpp = qp * (1 + qexpdp)\)
    	\State \(qexpw = qw * (1 + qexpdw)\)
    	\State \(qexps = qs * (1 + qexpds)\)
        \EndFunction
    \end{algorithmic}
\end{algorithm}

\caption{Quarterly Targ}

    \end{algorithmic}
\end{algorithm}

\begin{algorithm}[!htbp]
\caption{Quarterly Exp (Market)}
    \begin{algorithmic}
        \Function{Market::quarterly\_exp}{}
        \State \(qexpdpim = \frac{\Call{sum}{qq * qexpdp}}{\Call{sum}{qq}}\)
        \State \(qexppim = (1 - txva2) * qpdom * (1 + qexpdpim)\)
        \EndFunction
    \end{algorithmic}
\end{algorithm}

\begin{algorithm}[!htbp]
\caption{Quarterly Exp (External)}
    \begin{algorithmic}
        \Function{External::quarterly\_exp}{}

        \State \(qexppim=(1 - txva2) * qpdom * (1 + qexpdpim)\)
        \EndFunction
    \end{algorithmic}
\end{algorithm}

\subsubsection{Production Frontier}

\begin{algorithm}[H]
\caption{Prodfront}
    \begin{algorithmic}
        \Function{prodfront}{}
        \ForAll{markets}
        \State \(mtec = mtec * (1 + qdmtec)\)
        \EndFor
        \ForAll{firms}
        \State \Call{Firm::prodfront}{}
        \EndFor
        \EndFunction
    \end{algorithmic}
\end{algorithm}

\begin{algorithm}[!htbp]
\caption{Prodfront (Firm)}
    \begin{algorithmic}
        \Function{Firm::prodfront}{}
        \State \(qtop = qtop * (1 - rho)\)
        \State \(qchqtop1 = (1 - loss) * \frac{qinv * inveff}{qp}\)
        \State \(qchqtop2 = \Call{min}{loss * \frac{qinv * inveff}{qp} * \frac{resmax-res}{resmax}, (qtop + qchqtop1) * \frac{resmax - res}{1 - resmax}}\)
        \State \(qchqtop = qchqtop1 + qchqtop2\)
        \\
        \State \(res = \frac{res * (qtop + qchqtop1) + qchqtop2}{qtop + qchqtop}\)
        \If{\(res < 0\) or \(res > resmax\)}
        \State exit simulation
        \EndIf
        \\
        \State \(tec = \frac{qtop + qchqtop}{\frac{qtop}{tec} + \frac{qchqtop}{mtec}}\)
        \State \(qtop = qtop + qchqtop\)
        \EndFunction
    \end{algorithmic}
\end{algorithm}

\subsubsection{Target Search}

\begin{algorithm}[H]
\caption{Target Search}
    \begin{algorithmic}
        \Function{Firm::target\_search}{}
        \State \(qexppnet = qexpp - share * (io \times (qpdom * (1 - txva2)))\)
        \\
        \If{\(qplanq \geq qtop * (1 - res) * wtix\)}
        \State \Return \Call{plan\_implies\_recruitment}{}
        \EndIf
        \\
        \If{\(qplanq > \Call{qfr}{l}\)}
            \If{\(\Call{sat}{qplanq, \Call{rfq}{qplanq}}\)}
                \State \(qplanl = \Call{rfq}{qplanq}\)
                \State \Call{handle\_layoffs}{}
                \State \Return true
            \EndIf
            \State \Return \Call{plan\_implies\_recruitment}{}
        \EndIf
        \\
        \If{\(\Call{sat}{qplanq, l}\)}
            \State \(qplanl = l\)
            \State \Call{handle\_layoffs}{}
            \State \Return true
        \EndIf
        \\
        \State \Return \Call{try\_increase\_production}{}
        \EndFunction
    \end{algorithmic}
    \small The firm's market's io is matrix multiplied with market prices.
\end{algorithm}

\begin{algorithm}[!htbp]
\caption{Plan Implies Recruitment}
    \begin{algorithmic}
        \Function{Firm::plan\_implies\_recruitment}{}
        \If{\(\Call{sat}{\Call{qfr}{l}, l}\)}
            \State \Call{solve}{}
            \State \Call{handle\_layoffs}{}
            \State \Return true
        \EndIf
        \State \Return \Call{try\_reduce\_slack(\Call{qfr}{l}}{}
        \EndFunction
    \end{algorithmic}
\end{algorithm}

\begin{algorithm}[!htbp]
\caption{Try Reduce Production}
    \begin{algorithmic}
        \Function{Firm::try\_reduce\_production}{}
        \If{\(\Call{sat}{qplanq, \Call{rfq}{qplanq}}\)}
        \State \Call{solve}{}
        \State \Call{handle\_layoffs}{}
        \State \Return true
        \EndIf
        \State \Return \Call{try\_reduce\_slack}{qplanq}
        \EndFunction
    \end{algorithmic}
\end{algorithm}

\begin{algorithm}[!htbp]
\caption{Try Increase Production}
    \begin{algorithmic}
        \Function{Firm::try\_increase\_production}{}
        \State \(q2 = \Call{min}{\Call{qfr}{l}, qexpsu + maxsto - sto}\)
        \\
        \If{\Call{sat}{q2, l}}
        \State \(qplanq = \frac{l * \frac{qexpw}{4}}{(1 - qtargm) * qexppnet}\)
        \State \(qplanl = l\)
        \State \Call{handle\_layoffs}{}
        \State \Return true
        \EndIf
        \\
        \If{\(q2 = \Call{qfr}{l}\)}
            \State \Return \Call{try\_reduce\_production}{}
        \EndIf
        \\
        \If{\(\Call{sat}{q2, \Call{rfq}{q2}}\)}
            \State \(qplanq = q2\)
            \State \(qplanl = \frac{(1 - qtargm) * q2 * qexppnet}{\frac{qexpw}{4}}\)
            \State \Call{handle\_layoffs}{}
            \State \Return true
        \EndIf
        \\
        \State \Return \Call{try\_reduce\_production}{}
        \EndFunction
    \end{algorithmic}
\end{algorithm}

\begin{algorithm}[!htbp]
\caption{Try Reduce Slack}
    \begin{algorithmic}
        \Function{Firm::try\_reduce\_slack}{q7}
        \If{\(\Call{sat}{q7, \Call{rfq}{\frac{1 - res}{1 - resdown * res} * q7}}\)}
        \State \(qplanq = q7\)
        \State \(qplanl = \frac{(1 - qtargm) * q7 * qexppnet}{\frac{qexpw}{4}}\)
        \State \(res = 1 - \frac{q7 * (1 - res)}{\Call{qfr}{qplanl}}\)
        \State \Call{handle\_layoffs}{}
        \State \Return true
        \EndIf
        \\
        \State \(res = res * resdown\)
        \\
        \If{\Call{sat}{0, 0}}
        \State \Call{solve}{}
        \State \Call{handle\_layoffs}{}
        \State \Return true
        \EndIf
        \\
        \State \Return false
        \EndFunction
    \end{algorithmic}
    \small If no production plan can be found, false is returned and the firm is nullified.
\end{algorithm}

\begin{algorithm}[!htbp]
\caption{Handle Layoffs}
    \begin{algorithmic}
        \Function{Firm::handle\_layoffs}{}
        \State \(layoff = \Call{max}{0, l - qplanl}\)
        \State \(aman\left[0\right] = \Call{min}{layoff, aman\left[1\right]}\)
        \State \(aman\left[1\right] = \Call{min}{layoff - aman\left[0\right], aman\left[2\right]})\)
        \State \(aman\left[2\right] = layoff - aman\left[0\right] - aman\left[1\right]\)
        \EndFunction
    \end{algorithmic}
\end{algorithm}

\begin{algorithm}[H]
\caption{Labour Search}
    \begin{algorithmic}
        \Function{labour\_search}{}
        \ForAll{firms}
        \State \(ww = qw + iota * (qexpw - qw)\)
        \State \(ll = l\)
        \If{\(chm > 0\)}
        \State \(chl = qplanl - l\)
        \Else
        \State \(chl = \Call{rfq}{qplanq} - l\)
        \EndIf
        \EndFor
        \State \(ll = lu\)
        \\
        \State Sort firms in descending order of \(\frac{chl}{ll}\)
        \For{\(iter = 0, 1, \dots,niter-1\)}
        \ForAll{firms}
        \If{\(chl \leq 0\)}
        \State go to next firm
        \EndIf
        \State \(i = this firm\)
        \State \(target = \Call{choose\_labour\_target}{}\)
        \If{target is the unemployment pool}
        \State \Call{handle\_successful\_attack}{}
        \algstore{laboursearch}
    \end{algorithmic}
\end{algorithm}

\begin{algorithm}[H]
    \begin{algorithmic}
        \algrestore{laboursearch}
        \Else
            \If{\(ww\left[i\right] > ww\left[target\right] * (1 - gamma)\)}
            \State \Call{handle\_successful\_attack}{}
        \Else
            \State \(ww\left[i\right] = ww\left[i\right] + ksi * (ww\left[target\right] * (1 + gamma) - ww\left[i\right])\)
            \EndIf
        \EndIf
        \EndFor
        \EndFor
        \\
        \ForAll{firms}
        \State \(qchl = ll - l\)
        \State \(qchw = ww - qw\)
        \EndFor
        \State \(lu = ll\)
        \\
        \ForAll{firms}
        \State \Call{handle\_labour\_search\_layoffs}{}
        \EndFor
        \EndFunction
    \end{algorithmic}
    \small chl, ww, and ll are temporary vectors.
    \small ww and chl store firms' wage and desired change in labour.
    \small ll stores firms' labour, concatenated to the unemployment pool.
\end{algorithm}

\begin{algorithm}[!htbp]
\caption{Handle Successful Attack}
    \begin{algorithmic}
        \Function{handle\_successful\_attack}{}
        \State \(now = \Call{min}{theta * ll\left[target\right], chl\left[i\right]}\)
        \State \(ll\left[i\right] = ll\left[i\right] + now\)
        \State \(chl\left[i\right] = chl\left[i\right] - now\)
        \State \(ll\left[target\right] = ll\left[target\right] - now\)
        \If{\(target\) is a firm}
            \State \(chl\left[target\right] = chl\left[target\right] + now\)
        \EndIf
        \EndFunction
    \end{algorithmic}
\end{algorithm}

\begin{algorithm}[!htbp]
\caption{Handle Labour Search Layoffs}
    \begin{algorithmic}
        \Function{Firm::handle\_labour\_search\_layoffs}{}
        \State \(exit = \Call{max}{0, -qchl}\)
        \If{\(exit > aman\left[0\right] + aman\left[1\right]\)}
        \State \(aman\left[2\right] = \Call{max}{0, aman\left[2\right] - (exit - aman\left[0\right] - aman\left[1\right]}\)
        \EndIf
        \If{\(exit > aman\left[0\right]\)}
        \State \(aman\left[1\right] = \Call{max}{0, aman\left[1\right] - (exit - aman\left[0\right])}\)
        \EndIf
        \If{\(exit > 0\)}
        \State \(aman\left[0\right] = \Call{max}{0, aman\left[0\right] - exit}\)
        \EndIf
        \EndFunction
    \end{algorithmic}
\end{algorithm}

\begin{algorithm}[!htbp]
\caption{Labour Update}
    \begin{algorithmic}
        \Function{labour\_update}{}
        \ForAll{firms}
        \State \(sack = \Call{min}{aman\left[0\right], \Call{max}{0, l + qchl - qplanl}}\)
        \State \(qchl = qchl - sack\)
        \State \(aman\left[0\right] = aman\left[0\right] - sack\)
        \State \(lu = lu + sack\)
        \EndFor
        \\
        \State \(qdwind = \frac{\frac{\Call{sum}{(l + qchl) * (qw + qchw)}}{\Call{sum}{l + qchl}}}{\frac{\Call{sum}{l * qw}}{\Call{sum}{l}} - 1}\)
        \\
        \ForAll{firms}
        \State \(l = l + qchl\)
        \State \(qdw = \frac{qchw}{qw}\)
        \State \(qw = qw + qchw\)
        \\
        \State \(qchru = \frac{lu}{(lu + Government::l + \Call{sum}{Firm::l}) - ru}\)
        \State \(ru = ru + qchru\)
        \EndFor
        \EndFunction
    \end{algorithmic}
    \small qdwind sums across firms.
\end{algorithm}

\begin{algorithm}[H]
\caption{Planqrevise}
    \begin{algorithmic}
        \Function{Firm::planqrevise}{}
        \State \(qplanq = \Call{min}{qplanq, \Call{qfr}{l}}\)
        \State \(qdq = \frac{qplanq}{qq} - 1\)
        \State \(qq = qq * (1 + qdq)\)
        \\
        \For{\(i = 0, 1,\dots,NSEC - 1\)}
        \State \(qimq\left[i\right] = \Call{max}{0, share * io\left[i\right] * qplanqsave + \frac{optimsto\left[i\right] - imsto\left[i\right]}{4 * tmimsto}}\)
        \EndFor
        \For{\(i = 0, 1, \dots, NSEC - 1\)}
        \State \(imsto\left[i\right] = \Call{min}{maximsto\left[i\right], imsto\left[i\right] + qimq\left[i\right] - share * io\left[i\right] * qq}\)
        \EndFor
        \\
        \State \(qtopsu = \Call{max}{0, qq * \frac{\frac{qexpsu}{qexpsu + (optsto - sto)}}{4 * tmsto}}\)
        \EndFunction
    \end{algorithmic}
\end{algorithm}

\subsubsection{Market Confront}

\begin{algorithm}[H]
\caption{Market Confront}
    \begin{algorithmic}
        \Function{market\_confront}{}
        \ForAll{markets}
        \If{\(qpdom > qpfor\)}
        \State \(imp = imp + \frac{1 - imp}{4 * tmimp} * \frac{qpdom * (1 - txva2) - qpfor}{qpfor}\)
                \Else
        \State \(imp = imp - \frac{imp}{4 * tmimp} * \frac{qpfor - qpdom * (1 - txva2)}{qpdom * (1 - txva2)}\)
        \EndIf
        \State \(pt = (1 - imp) * qprelpdom + imp * \frac{qpfor}{1 - txva2}\)
        \EndFor
        \ForAll{externals}
        \State \(pt = qpdom * (1 + qdp)\)
        \EndFor
        \For{\(i = 0, 1,\dots,NSEC - 1\)}
        \State \(qpurch\left[i\right] = gkoff\left[i\right] * Government::l * \frac{Government::qw}{4} * pt\left[i\right] * \frac{wgref}{100 * Government::qw}\)
        \EndFor
        \\
        \For{\(iter = 0, 1,\dots,marketiter-1\)}
        \State \Call{compute\_expenditures}{}
        \State \Call{compute\_buying}{}
        \If{\(iter = marketiter - 1\)}
        \ForAll{markets}
        \State \Call{price\_adjust}{}
        \EndFor
        \EndIf
        \EndFor
        \EndFunction
    \end{algorithmic}
    \small Clamp imp between 0 and 1.
\end{algorithm}

\begin{algorithm}[!htbp]
\caption{Compute Expenditures}
    \begin{algorithmic}
        \Function{Household::compute\_expenditures}{}
        \State \(qprelcpi = \frac{\Call{sum}{qc}}{\Call{sum}{\frac{qc}{pt}}}\)
        \State \(qchdcpi = \frac{qprelcpi}{qcpi} - 1 - qdcpi\)
        \\
        \ForAll{\(i = 0, 1, \dots, NEXPH- 1\)}
        \If{\(i \neq DUR\) and \(i \neq SAV\)}
        \State \(qspe\left[i\right] = cva\left[i\right] * pt\left[i\right]\)
        \EndIf
        \EndFor
        \\
        \State \(swap = alfa3 * (\frac{qchri}{4} - qchdcpi) + alfa4 * qchru\)
        \State \(qspe\left[DUR\right] = \Call{max}{0, \frac{pt\left[DUR\right] * cva\left[DUR\right]}{rhodur} - \frac{pt\left[DUR\right]}{qp\left[DUR\right]} * (1 - rhodur) * stodur - qdi * swap}\)
        \State \(qspe\left[SAV\right] = (whra * qdi - wh) + qdi * swap\)
        \\
        \For{\(i = 0, 1,\dots,NEXPH - 1\)}
        \State \(qsp\left[i\right] = beta1\left[i\right] * qspe\left[i\right] + (beta2\left[i\right] + \frac{beta3\left[i\right] * qprelcpi}{qdi - qspsavreq}) * (qdi - qspsavreq - \Call{sum}{qspe\left[i\right] * beta1\left[i\right]})\)
        \If{\(i \neq SAV\)}
        \State \(qsp\left[i\right] = \Call{max}{0, qsp\left[i\right]}\)
        \EndIf
        \EndFor
        \State \(qsp\left[SAV\right] = qsp\left[SAV\right] + qspsavreq\)
        \EndFunction
    \end{algorithmic}
    \small Clamp swap between -0.05 and -0.05
\end{algorithm}

\begin{algorithm}[H]
\caption{Compute Buying}
    \begin{algorithmic}
        \Function{compute\_buying}{}
        \ForAll{markets}
        \For{\(i = 0, 1, \dots, NSEC - 1\)}
        \State \(qbuy\left[i\right] = \Call{sum}{qimq\left[i\right]}\)
        \EndFor
        \EndFor
        \\
        \For{\(i = 0, 1, \dots, NSEC- 1\)}
        \State \(Government::qbuy\left[i\right] = \frac{qpurch\left[i\right]}{pt\left[i\right]}\)
        \State \(Household::qbuy\left[i\right] = nh * \frac{qsp\left[i\right]}{pt\left[i\right]}\)
        \\
        \State \(qinvtot = omegag\left[i\right] * Government::qinv\left[i\right] + omegabld\left[i\right] * qinvbld + omegain\left[i\right] * qinvin + omega\left[i\right] * \Call{sum}{qinvlag}\)
        \State \(Bank::qbuy\left[i\right] = \frac{qinvtot}{pt\left[i\right] * \frac{1 - txva2}{1 - txva1}}\)
        \EndFor
        \\
        \ForAll{externals}
        \State \(qq = \Call{invert\_matrix}{I - (io3 * \frac{1- imp}{1 - x})} * \Call{sum}{qbuy * \frac{1 - imp}{1 - x}}\)
        \For{\(i = 0, 1,\dots, NSEC - 1\)}
        \State \(qbuy\left[i\right] = io\left[i\right] * qq\)
        \EndFor
        \EndFor
        \\
        \ForAll{sectors}
        \State \(qtbuy = \Call{sum}{qbuy}\)
        \EndFor
        \EndFunction
    \end{algorithmic}
    \small Sum across firms per market for \(Market::qbuy\left[i\right]\).\\
    \small Matrix inversion requires the entire matrix intact. io3 is temporarily constructed from the externals' io.\\
    \small The sum across qbuy is total buying from the current external.\\
    \small qtbuy is total buying from each sector.
\end{algorithm}

\begin{algorithm}[!htbp]

        \State \(pt = pt - ch\)
        \Else
        \State \(pt = pt + ch\)
        \EndIf
        \EndFunction
    \end{algorithmic}
    \small Sum across firms per market.
\end{algorithm}

        \EndFor
        \\
        \State \(whra = smooth\left[SAV\right] * whra + (1 - smooth\left[SAV\right]) * \frac{wh}{qdi}\)
        \\
        \For{\(i = 0, 1, \dots, NSEC-1\)}
        \State \(qp\left[i\right] = pt\left[i\right]\)
        \EndFor
        \\
        \State \(oldqcpi = qcpi\)
        \State \(qcpi = \frac{\Call{sum}{qc}}{\Call{sum}{\frac{qc}{qp}}}\)
        \State \(qdcpi = \frac{qcpi - oldqcpi}{oldqcpi}\)
        \EndFunction
    \end{algorithmic}

\begin{algorithm}[!htbp]
\caption{Firm Sto}
    \begin{algorithmic}
        \Function{firm\_sto}{}
        \ForAll{firms}
        \State \(limsto = sto + qq - qsufor\)
        \State \(lower = \Call{min}{limsto, minsto}\)
        \State \(upper = \Call{min}{limsto, maxsto}\)
        \EndFor
        \\
        \State \(qsubsdom = 0\)
        \ForAll{markets}
        \State \(totchsto = \Call{min}{\Call{sum}{qq - qsufor} - qtsudom, \Call{sum}{upper - sto}}\)
        \State \(qchtsto = totchsto\)
        \State \(qwaste = \Call{sum}{qq - qsufor} - qtsudom - totchsto\)
        \\
        \ForAll{firms in market}
        \If{\(sto > upper\)}
        \State \(ch = upper - sto\)
        \Else
        \State \(ch = lower - sto\)
        \EndIf
        \State \(sto = sto + ch\)
        \State \(qchsto = ch\)
        \State \(totchsto = totchsto - ch\)
        \EndFor
        \\
        \State \(diff1 = \Call{sum}{upper - sto}\)
        \State \(diff2 = \Call{sum}{lower - sto}\)
        \ForAll{firms in market}
        \If{\(totchsto > 0\)}
        \State \(ch = \frac{upper - sto}{diff1} * totchsto\)
        \Else
        \State \(ch = \frac{lower - sto}{diff2} * totchsto\)
        \EndIf
        \State \(sto = sto + ch\)
        \State \(qchsto = qchsto + ch\)
        \\
        \State \(qsudom = qq - qsufor - qchsto\)
        \State \(qsdom = qsudom * (1 + rsubs) * qpdom * (1 - txva2)\)
        \EndFor
        \\
        \State \(qsubsdom = qsubsdom + \Call{sum}{qsudom * rsubs * qpdom * (1 - txva2)}\)
        \EndFor
        \EndFunction
    \end{algorithmic}
    \small Sums across firms are per market.
\end{algorithm}

\begin{algorithm}[H]
\caption{Reference Inventory Levels}
    \begin{algorithmic}
        \Function{Firm::reference\_inventory\_levels}{}
        \State \(j = relative\_quarter + 1\)
        \State \(curs = 4 * \frac{s * (1 + \frac{histds}{4})^{j+1.5} + cums * (1 + \frac{histds}{4})^{\frac{j-1}{2}}}{j + 4}\)
        \State \(curp = \frac{4 * p * (1 + \frac{histdp}{4})^{j + 1.5} + j * cump * (1 + \frac{histdp}{4})^{\frac{j - 1}{2}}}{j + 4}\)
        \\
        \State \(minsto = small * \frac{curs}{curp}\)
        \State \(maxsto = big * \frac{curs}{curp}\)
        \State \(optsto = minsto + beta * (maxsto - minsto)\)
        \\
        \For{\(i = 0, 1, \dots, NSEC-1\)}
        \State \(minimsto\left[i\right] = imsmall * io\left[i\right] * share * \frac{curs}{curp}\)
        \State \(maximsto\left[i\right] = imbig * io\left[i\right] * share * \frac{curs}{curp}\)
        \State \(optimsto\left[i\right] = minimsto\left[i\right] + imbeta * (maximsto\left[i\right] - minimsto\left[i\right])\)
        \EndFor
        \EndFunction
    \end{algorithmic}
    \small io refers to the firm's market's io
\end{algorithm}

\subsection{Final Quarterly Prices, Sales, and Margin}

\begin{algorithm}[H]
\caption{Finalqpqsqm}
    \begin{algorithmic}
        \Function{Firm::finalqpqsqm}{}
        \State \(qsu = qsufor + qsudom\)
        \State \(qds = \frac{qsfor + qsdom - qs}{qs}\)
        \State \(qs = qsfor + qsdom\)
        \State \(qdp = \frac{\frac{qs}{qsu} - qp}{qp}\)
        \State \(qp = \frac{qs}{qsu}\)
        \State \(qdva = qq * \frac{qp - \Call{sum}{io \times (qpdom * (1 - txva2)}}{qva} - 1\)
        \State \(qva = qva * (1 + qdva)\)

\begin{algorithm}[!htbp]
\caption{Credit Market}
    \begin{algorithmic}
        \Function{Bank::credit\_market}{}
        \State \(qdemfund = \Call{max}{0, -Government::qchpos} + \Call{sum}{\Call{max}{0, qdeschbw}}\)
        \\
    \State \(qsupfund1 = \frac{liqb + qchliqb + \Call{sum}{qdeschk2} - rfund1 * (\Call{sum}{bw} + Government::bw + \Call{max}{0, -wh * nh})}{1 + rfund1}\)
        \State \(qsupfund2 = liqb + qchliqb + \Call{sum}{qdeschk2} - rfund2 * (\Call{sum}{k2 + qdeschk2} + Government::dep + \Call{max}{0, wh * nh})\)
        \State \(qsupfund = \Call{max}{0, \Call{min}{qsupfund1, qsupfund2}}\)
        \\
        \State \(qsavhreq = \Call{min}{kappa1 * \Call{max}{0, qdi * nh}, \Call{max}{0, qdemfund - qsupfund}}\)
        \State \(qredtbw = \Call{min}{kappa2 * \Call{sum}{\Call{max}{0, qdeschbw}}, \Call{max}{0, qdemfund - qsupfund - qsavhreq}}\)

        \State \(qchbw = qdeschbw - qredtbw * \frac{\Call{max}{0, qdeschbw}}{\Call{sum}{\Call{max}{0, qdeschbw}}}\)
        \EndFor
        \\
        \State \(qchri = lamda1 * \frac{qdemfund - qsupfund}{\Call{max}{1, qdemfund}}\)
        \State \(ri = ri + qchri\)

\begin{algorithm}[!htbp]

        \Else
        \State $margin = 1 - \frac{\frac{qexpw}{4}}{wtix * (1 - res) * tec * qexppnet}$
        \EndIf
        \\
        \If{$magin \geq qtargm$}
        \State \Return true
        \Else

        \EndIf
        \EndFunction
    \end{algorithmic}

\begin{algorithm}[!htbp]
\caption{Delay}
    \begin{algorithmic}
        \Function{Firm::delay}{}
        \State \(delta = \frac{1}{1 + \frac{4 * tminv}{3}}\)
        \\
        \State \(inv\_delay\left[2\right] = inv\_delay\left[2\right] + qinvlag\)
        \State \(inv\_delay\left[1\right] = inv\_delay\left[1\right] + delta * inv\_delay\left[2\right]\)
        \State \(inv\_delay\left[2\right] = inv\_delay\left[2\right] - delta * inv\_delay\left[2\right]\)
        \State \(inv\_delay\left[0\right] = inv\_delay\left[0\right] + delta * inv\_delay\left[1\right]\)
        \State \(inv\_delay\left[1\right] = inv\_delay\left[1\right] - delta * inv\_delay\left[1\right]\)
        \\
        \State \(ret = delta * inv\_delay\left[0\right]\)
        \State \(inv\_delay\left[0\right] = inv\_delay\left[0\right] * (1 - delta)\)
        \State \Return \(ret\)
        \EndFunction
    \end{algorithmic}
\end{algorithm}

\begin{algorithm}[!htbp]
\caption{Bw Ratio}
    \begin{algorithmic}
        \Function{Firm::check\_bw}{bw\_ratio}
        \State \(val = 1 - bw\_ratio\)
        \If{\(val > 0.3\)}
        \State \Return 1
        \ElsIf{\(val \leq 0.1\)}
        \State \Return 0
        \Else
        \State \Return \(0.0025 * (\Call{floor}{100 * val + 0.5} - 10)^2\)
        \EndIf
        \EndFunction
    \end{algorithmic}
    \small \Call{floor}{} rounds down to the nearest integer.
\end{algorithm}

\begin{algorithm}[!htbp]
\caption{Solve}
    \begin{algorithmic}
        \Function{Firm::solve}{}
        \State $MAX\_ITERATIONS = 100$
        \State $TOLERANCE = 0.001$
        \State $b = \frac{qexpw}{(1 - qtargm) * wtix * (1 - res) * tec * qexppnet * 4}$
        \State $y = \frac{1}{b}$
        \\
        \For{$i = 0,1, \dots,MAX\_ITERATIONS - 1$}
        \State $f = b * y + e^{-y} - 1$
        \State $f\_prime = b - e^{-y}$
        \State $delta = \frac{f}{f\_prime}$
        \State $y = y - delta$
        \\
        \If{$|delta| < TOLERANCE$}
        \State $qplanl = y * \frac{qtop}{tec}$
        \State $qplanq = \Call{qfr}{qplanl}$
        \State \Return
        \EndIf
        \EndFor
        \EndFunction
    \end{algorithmic}
    \small Newton-Rhapson method.
\end{algorithm}

\begin{algorithm}[H]
\caption{Choose Labour Target}
    \begin{algorithmic}
        \Function{choose\_labour\_target}{}
        \State $len = $ length of $ll$ \Comment{(firm labour concatenated to the unemployment pool)}
        \State $scaled\_unemployment = ll\left[len - 1\right] * skrepa$
        \State $total\_labour = \Call{sum}{ll} - ll\left[len - 1\right] + scaled\_unemployment$
        \State $rand\_val = $ random value between $0$ and $total\_labour$
        \\
        \State $target = ll\left[len - 1\right]$ \Comment{default to unemployment pool}{}
        \State $cumsum = 0$
        \For{$j = 0,1,\dots,len - 1$}
        \If{$j$ is the unemployment pool}
        \State $cumsum = cumsum + scaled\_unemployment$
        \Else
        \State $cumsum = cumsum + ll\left[j\right]$
        \EndIf
        \If{$cumsum > rand\_val$}
        \State $target = j$
        \State \textbf{break}
        \EndIf
        \EndFor
        \State \Return target
        \EndFunction
    \end{algorithmic}
\end{algorithm}

\section{Variable List}

Simulation variables are categorised by class. $double$ is the data type for real numbers. $int$ is the data type for integers. $const$ specifies the variable remains constant during simulation. Data types ending with $(init)$ are initialised from csv files before simulation start. Square brackets indicates the variable is an array. For example, $ribwfor$ is a $const$ $double\left[120\right]$. This means the rate of interest on foreign borrowing is an array of 120 constant real numbers. In other words, the array is an exogenous input variable that controls the rate of interest on foreign borrowing for each simulation quarter.
